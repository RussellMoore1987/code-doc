Custom Elements

Custom elements allow you to define your own HTML elements with custom behavior and appearance. Make sure to use the custom.js and custom.css files to implement the custom behavior and styling for your elements.

Graphic Novel Viewer

Browse and read digital graphic novels in a full-featured reader. Supports single-page, two-page spread, three-page, and scroll/detail reading modes with zoom, bookmarks, table of contents, and automatic progress saving.

    Standalone Book Card

    Place a single book card anywhere using data-gn-card="book-id" on any element.

    <div data-gn-card="starbound-chronicles"></div>

    Open a Book from Any Element

    Add data-gn-open="book-id" to any element to open that book in the reader when clicked.

    <button data-gn-open="starbound-chronicles">Read Now</button>
<a href="#" data-gn-open="echoes-of-tomorrow">Echoes of Tomorrow</a>

    Graphic Novel Books Configuration

    How to Add a New Graphic Novel

    1. Copy one of the .graphic-novel-book blocks in the HTML.
    2. Give it a new unique data-book-id value.
      • Use lowercase letters and hyphens only.
      • Example: "my-new-book"
      • This ID is stored in localStorage, so keep it stable.
    3. Update .book-title text.
    4. Update .book-description text.
    5. Replace the <img> inside .book-cover with your cover image.
    6. Replace or add <img> elements inside .book-pages.
      • Pages display in DOM order (first img = Page 1).
      • Write meaningful alt text for each page.
    7. Update or remove .book-toc.
      • Each .book-chapter marks a chapter.
      • data-page is the 1-based page number where the chapter starts.
      • The element's text is the chapter name shown in the TOC.
    8. Optionally fill in .book-author, .book-year, .book-genre.
    9. Save the file. The book appears automatically in the Library. No changes to custom.js or custom.css are needed.

    Element Reference

    Element / Attribute Required? Description
    .graphic-novel-bookRequiredIdentifies this div as a book.
    data-book-id="unique-id"RequiredUnique ID (used for localStorage).
    .book-titleRequiredBook title text.
    .book-descriptionRequiredShort description text.
    .book-cover imgRequiredCover <img src="..." alt="...">.
    .book-pagesRequiredContainer for page images.
    .book-pages imgRequiredPage images; top-to-bottom = page order. At least one required.
    .book-authorOptionalAuthor name.
    .book-yearOptionalPublication year.
    .book-genreOptionalGenre label (shown as a badge).
    .book-tocOptionalTable of Contents container.
    .book-chapter[data-page="N"]OptionalChapter entry; text = name, data-page = start page.

    localStorage / Reading Progress

    Each book saves its progress under the key gn-progress-{data-book-id}. The stored JSON is { lastPage, bookmark, viewMode }. Each book's progress is completely independent. Clearing localStorage resets all reading progress.

    Note: The .graphic-novel-book divs are hidden in the normal page layout via CSS. They exist solely to configure the viewer. The Graphic Novel modal is built and managed by custom.js.
