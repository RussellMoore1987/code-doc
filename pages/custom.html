Custom Elements

Custom elements allow you to define your own HTML elements with custom behavior and appearance. Make sure to use the custom.js and custom.css files to implement the custom behavior and styling for your elements.

Graphic Novel Viewer

Browse and read digital graphic novels in a full-featured reader. Supports single-page, two-page spread, three-page, and scroll/detail reading modes with zoom, bookmarks, table of contents, and automatic progress saving.

    Standalone Book Card

    Place a single book card anywhere using data-gn-card="book-id" on any element.

    <div data-gn-card="starbound-chronicles"></div>

    Open a Book from Any Element

    Add data-gn-open="book-id" to any element to open that book in the reader when clicked.

    <button data-gn-open="starbound-chronicles">Read Now</button>
<a href="#" data-gn-open="echoes-of-tomorrow">Echoes of Tomorrow</a>
