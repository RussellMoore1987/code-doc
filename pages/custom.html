Custom Elements

Custom elements allow you to define your own HTML elements with custom behavior and appearance. Make sure to use the custom.js and custom.css files to implement the custom behavior and styling for your elements.

Graphic Novel Viewer

Browse and read digital graphic novels in a full-featured reader. Supports single-page, two-page spread, three-page, and scroll/detail reading modes with zoom, a magnifier/loupe, bookmarks, a table of contents, fullscreen, automatic progress saving, deep-linkable URLs, and one-click PDF export (via the browser's print dialog). Novel-type books (data-book-type="novel") additionally get text highlighting and read-aloud (text-to-speech).

    Standalone Book Card

    Place a single book card anywhere using data-gn-card="book-id" on any element.

    <div data-gn-card="starbound-chronicles"></div>

    Open a Book from Any Element

    Add data-gn-open="book-id" to any element to open that book in the reader when clicked.

    <button class="gn-page-card-open-btn" data-gn-open="starbound-chronicles">Read Now</button>
<a href="#" data-gn-open="echoes-of-tomorrow">Echoes of Tomorrow</a>

    Graphic Novel Books Configuration

    How to Add a New Graphic Novel

    1. Copy one of the .graphic-novel-book blocks in the HTML.
    2. Give it a new unique data-book-id value.
      • Use lowercase letters and hyphens only.
      • Example: "my-new-book"
      • This ID is stored in localStorage, so keep it stable.
    3. Update .book-title text.
    4. Update .book-description text.
    5. Replace the <img> inside .book-cover with your cover image.
    6. Replace or add <img> elements inside .book-pages.
      • Pages display in DOM order (first img = Page 1).
      • Write meaningful alt text for each page.
    7. Update or remove .book-toc.
      • Each .book-chapter marks a chapter.
      • data-page is the 1-based page number where the chapter starts.
      • The element's text is the chapter name shown in the TOC.
    8. Optionally fill in .book-author, .book-year, .book-genre.
    9. Save the file. The book appears automatically in the Library. No changes to custom.js or custom.css are needed.

    Element Reference

    Element / Attribute Required? Description

    Reader Toolbar & Controls

    These controls appear in the reader toolbar for every book. Rows marked "Novel only" only appear for data-book-type="novel" books.

    Control Availability Description
    First / Previous / Next / Last page, page number fieldAll booksJump to any page directly, or step through the book. Typing a page number and pressing Enter/blur jumps there.
    Single / Two-page / Three-page / Scroll viewAll books (three-page hidden for novels)Switches how pages are laid out. Scroll mode stacks every page vertically and supports continuous reading/scrolling.
    Zoom in / out / reset, zoom % fieldAll booksFor image books, zoom only applies in Scroll view (resizes page width). For novels, zoom scales the reading font size instead, in any view.
    Magnifier (loupe)All booksFollows the cursor with a zoomed-in preview — a panning close-up of the image for graphic novels, or an enlarged text clone for novels.
    BookmarkAll booksBookmarks the current page/spread. The dropdown next to the button lists every bookmark in the book for quick navigation or removal.
    HighlightsNovel onlyOpens the right-side Highlights panel. See the Read-Aloud & Highlights tab.
    Table of ContentsAll books (only useful with .book-chapter entries)Opens the right-side chapter list; the active chapter is highlighted based on the current page.
    FullscreenAll booksToggles the browser's fullscreen mode for the reader.
    Export to PDFAll booksRenders every page into a hidden print layout and opens the browser's print dialog ("Save as PDF" uses the book's title as the suggested filename).
    Read Aloud, Skip ±10 words, Prev/Next page, Auto-advance, Read From Here, Voice, SpeedNovel only (requires browser speech-synthesis support)Text-to-speech playback. See the Read-Aloud & Highlights tab.

    Novel Page Image Layout Classes

    For data-book-type="novel" books, each page fragment (referenced via data-page-src) renders inside .gn-text-page. Use these classes on the <img> tags and their wrapping <div> within that fragment to lay out images among the prose.

    Class Applies To Description
    .gn-img-full<img>Single full-width image with prose spacing.
    .gn-img-rowWrapping <div>Flex row container that splits any number of images evenly (2, 3, or more) side by side.
    .gn-flex-10 … .gn-flex-90<img> inside .gn-img-rowFlex-grow weight for uneven splits - pair e.g. gn-flex-60 with gn-flex-40 for a 60/40 split, or gn-flex-20 with gn-flex-80 for 20/80.

</div>

    Deep-Linkable URLs

    Opening a book updates the URL's query string to ?gnbook=book-id&gnpage=N (1-indexed page). Sharing or reloading a URL with these params automatically opens straight to that book/page; the params are cleared when returning to the library or closing the reader.

    localStorage / Reading Progress

    Each book saves its progress under the key gn-progress-{data-book-id}. The stored JSON is { lastPage, bookmarks, viewMode, zoom, ttsProgress, ttsPanelOpen, hlPanelOpen }:

    Field Description
    lastPage0-indexed page/spread the reader was last on.
    bookmarksArray of 0-indexed bookmarked page numbers.
    viewModesingle | double | triple | scroll.
    zoomCurrent zoom level (font-size multiplier for novels, image-width multiplier for image books in scroll mode).
    ttsProgressNovel only. { page, wordIndex } resume point for read-aloud, or null.
    ttsPanelOpenNovel only. Whether the read-aloud controls row was expanded.
    hlPanelOpenNovel only. Whether the right-side Highlights panel was open.

    Each book's progress is completely independent. Clearing localStorage resets all reading progress.

    Read-Aloud / Text-to-Speech (Novel Books Only)

    For data-book-type="novel" books, the Read Aloud toolbar group (only shown when the browser supports speechSynthesis) reads the current page aloud, highlighting each word as it's spoken and auto-scrolling to keep it in view. Controls include: play/pause (R), skip back/forward 10 words, jump to the previous/next page and keep reading, an auto-advance toggle (continues into the next page automatically), a voice picker, and a playback speed picker (0.5x–2x). A "Read From Here" mode lets you right-click any word (or a text selection) to start reading from that exact point.

    Playback position is remembered per book (resumes where you left off), and a "p{page} ~{N} min read" badge estimates reading time for the current page based on its word count.

    Text Highlighter (Novel Books Only)

    For data-book-type="novel" books, selecting text in the reader pops up a small options popup: 5 color swatches to create a highlight, a "Read from highlight" button that starts read-aloud from that spot, and a "Copy highlight text" button that copies the selected text to the clipboard. Clicking an existing highlight re-opens the same popup with a "Remove highlight" button in place of creating a new one — the read/copy buttons work identically whether the highlight has been saved yet or not.

    Use the toolbar's highlighter button (or press H) to open the right-side Highlights panel, which lists every highlight in the current book with a count badge, lets you search them by text or filter by color, click one to jump straight to its page (scrolling to and briefly flashing the exact highlighted text), or delete it.

    Highlights are stored independently from reading progress, under the key gn-highlights-{data-book-id}, as an array of { id, page, start, end, text, color, ts } objects (start/end are character offsets into that page's text). They persist even if progress is reset via "Read Again".

    Note: The .graphic-novel-book divs are hidden in the normal page layout via CSS. They exist solely to configure the viewer. The Graphic Novel modal is built and managed by custom.js.
