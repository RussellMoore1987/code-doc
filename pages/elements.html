HTML Elements

These sections cover the various HTML elements available in the DevDocs.

Quotes

Use <blockquote> for longer quotations or highlighted callout-style text that should remain semantically distinct from the surrounding content.

"Good documentation should be easy to scan, easy to trust, and easy to revisit later."

Some One :)

Code Blocks

DevDocs supports code blocks for displaying preformatted code snippets. These can be used to show examples, configurations, or any other code-related content. Code blocks are defined using the <pre> and <code> tags.

// Leaf node (has a page)
    {
      id: 'installation',
      label: 'Installation',
      page: 'pages/installation.html'
    }
    
    // Group node (has children, no page)
    {
      id: 'getting-started',
      label: 'Getting Started',
      children: [
        { id: 'intro', label: 'Introduction', page: 'pages/intro.html' }
      ]
    }
ℹ Note
  • Each code block should be properly formatted to ensure readability and consistency.
  • Each code block has a copy button for easy copying.

Callouts

ℹ Note

This documentation site is served as a static project. No server-side rendering or framework is required. All you need is a basic local HTTP server or your IDE's Live Server extension.

⚠ Never Expose API Keys Client-Side

Any secret embedded in JavaScript that runs in the browser is publicly visible to anyone who opens DevTools. Route all privileged API calls through a backend proxy or serverless function.

✖ Trailing-slash paths

On GitHub Pages, make sure all page paths in NAV_DATA use a relative path from the repository root (e.g., pages/intro.html), not an absolute path starting with /, or your fetches will fail. 

<div class="callout">
  <div class="callout-title">ℹ Info</div>
  <p>Your note here.</p>
</div>

Tables

Add .table-striped to any <table> element to get the standard striped style used throughout the documentation - styled header row, alternating row backgrounds, and consistent cell padding.

Name Type Description
idstringUnique identifier for the item
labelstringDisplay name shown in the UI
pagestringRelative path to the HTML page
childrenarrayNested nav items (groups only)
