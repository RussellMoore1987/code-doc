About Me

I've spent my career moving between two things I enjoy: writing code that solves a concrete business problem, and explaining how that code works to someone else. That combination shows up throughout my work - a content management system built to learn secure PHP practices, a dynamic tagging engine built for a real e-commerce customer, an open-source framework built together with students, and this documentation platform, built from scratch in vanilla JavaScript with no framework or build step.

I'm most useful on a team when there's an existing system that needs to get better - faster, more reliable, easier to extend - rather than torn out and replaced. I default to the smallest safe change that solves the problem, and I document what I find along the way so the next person (often me, months later) isn't starting from zero.
