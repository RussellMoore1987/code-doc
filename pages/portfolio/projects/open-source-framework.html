Open Source PHP Framework

A mini PHP framework built alongside my students - a dynamic active-record base class, an autoloader, pretty-URL routing, and a self-documenting REST API - designed so new projects could skip boilerplate and start on business logic immediately.

The Problem

Every new PHP project I (and my students) started began with the same repetitive setup: database connections, routing, basic CRUD boilerplate, before any real business logic could be written. I wanted a lightweight foundation that removed that repetition, and a real project my students could learn framework design from by building it.

My Role

Creator and lead developer, building the framework together with my students as part of their coursework at Bridgerland Technical College - a mix of hands-on architecture decisions and mentorship.

What I Built

  • A dynamic active-record model: extending one database object class and adding a few lines automatically gives a new class core CRUD functionality alongside any custom behavior it defines.
  • A class/trait autoloader plus internal page routing with clean, pretty URLs.
  • A REST API with auto-generated routing and auto-generated documentation.
  • Early UI mockups for an internal dashboard, a to-do/task integration, and a companion database tool.

Technologies & Approach

PHP with object-oriented design centered on the active-record pattern, a custom autoloader, and a self-documenting REST layer - the project is public on GitHub.

PHP Active Record Autoloading REST APIs Pretty-URL Routing

Challenges

Designing a base class flexible enough to support classes with genuinely unknown, project-specific shapes and requirements - without becoming so generic it stopped being useful - was the most sophisticated architecture problem I'd tackled up to that point, on top of the normal challenge of teaching the concepts while building them.

How They Were Solved

I leaned on advanced object-oriented PHP - traits, autoloading, and a carefully scoped active-record contract - so that "core" behavior (CRUD, basic querying) came for free from the base class, while anything project-specific stayed in the subclass rather than leaking back into the framework.

Outcome & Value Created

A reusable, open-sourced foundation that let new PHP projects (mine and my students') skip repetitive setup and start on real functionality sooner, plus a concrete teaching vehicle for advanced PHP concepts - autoloading, routing, and API design - that's hard to teach from a tutorial alone.
