AFB Theme (Snow Owl)

A platform-wide theme rebuild for Adilas For Business - organized, mobile-ready, and modern - rolled out across the entire system by changing a small number of shared includes and stylesheets rather than every individual page.

Quick Facts
RoleSole front-end/theme developer
ClientAFB / Adilas
TechHTML, CSS, shared template includes
ResultBecame the platform's standard theme

The Problem

Adilas needed a theme that organized information better, worked well on mobile, and simply looked and felt more modern than what existed - but the budget for the project was low, and the platform was large enough that rewriting every page individually wasn't realistic.

My Role

Sole developer for the theme, responsible for both the visual design direction and the implementation across the existing platform.

What I Built

  • A new theme ("Snow Owl") with 13 selectable color schemes.
  • Improved information architecture: up to 18 personal links per payee, 50+ corporation-wide links, organized into departments for easier access.
  • New text editors, data tables, and data "feeders" as part of the refreshed UI.
  • Training videos walking users through the new theme, published on the AFB YouTube channel.

Technologies & Approach

Rather than touching every page, I targeted a small number of shared elements - primarily the header and footer includes plus the CSS they load - so the visual and organizational changes propagated across the whole platform automatically.

HTML / CSS Shared Template Includes Responsive / Mobile-Ready Design

Challenges

The core challenge was leverage: how to touch as much of the platform's look and organization as possible while changing as little code as possible, on a genuinely low budget, without breaking any of the many existing pages that depended on the old header/footer/CSS.

How They Were Solved

I dissected the existing framework closely enough to find the handful of shared includes that every page already depended on, and concentrated the new design and organizational changes there - new CSS, a new header/footer structure, and configuration-driven color themes - so one focused change cascaded everywhere it needed to.

Outcome & Value Created

Snow Owl became the new standard theme across Adilas, and - per the product's own marketing - one of the more profitable products to come out of that work, while demonstrating that a tightly scoped, shared-file change can outperform a full per-page rewrite.
