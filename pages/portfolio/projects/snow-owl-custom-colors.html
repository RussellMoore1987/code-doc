Snow Owl Custom Colors

A live color customization tool for the Snow Owl theme, letting each corporation or payee choose their own color scheme from thousands of combinations - built with jQuery, with safe, reversible CSS overrides.

The Problem

After shipping the Snow Owl theme, corporations and individual payees wanted the ability to personalize its colors to match their own branding or preference, without needing a developer involved for every change.

My Role

Sole developer on both the settings UI and the underlying CSS override mechanism.

What I Built

  • A settings page offering thousands of possible color combinations for a corporation or payee's theme.
  • A live, jQuery-driven visual preview that updates as the user picks colors.
  • Safe revert-to-default behavior if a customer removes their custom colors.
  • A training video walking through the feature.

Technologies & Approach

Heavy jQuery and CSS work: overriding the theme's default CSS per account at runtime, driven by a jQuery visual display, without disturbing the rest of the settings page's own styling.

jQuery CSS Overrides Live Preview UI

Challenges

The visual display had to pull in the theme's current default colors, let the user override them live, and then cleanly revert back to those originals if the custom colors were removed - all without leaking style changes onto other, unrelated elements on the same settings page.

How They Were Solved

I scoped the override logic tightly: reading the existing default CSS values first, applying overrides only through a dedicated mechanism the jQuery display controlled, and restoring the original values explicitly on removal rather than assuming a reload would "fix" anything.

Outcome & Value Created

A shipped, self-service personalization feature that reduced the need for one-off developer involvement in branding requests, and a deeper, hands-on understanding of safely overriding and reverting CSS at runtime.
