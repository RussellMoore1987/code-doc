PHP CMS

A full content management system built from scratch in PHP - posts, categories, comments, users, a public site, and an admin dashboard - created as a deep-dive training project with a heavy emphasis on security.

Quick Facts
RoleSole developer
ContextIndependent / training project
TechPHP, MySQL, Ajax, jQuery, Bootstrap, Chart.js
FocusSecurity & framework-free architecture

The Problem

I wanted to move beyond front-end work and build a genuinely secure, full-featured backend system in PHP without leaning on an existing CMS or framework - including protecting it against the most common real-world attack vectors, not just making the features "work."

My Role

Sole developer, end to end: schema design, backend logic, security hardening, and the admin/public front ends.

What I Built

  • A public site with post display, search across categories/authors/tags/latest posts, and a moderated comment system (comments require admin approval before publishing).
  • An admin dashboard with drill-down charts and widgets - a post/comment activity feed built on Chart.js that can be searched by month and year, plus an Ajax/jQuery to-do list widget supporting add, edit, delete, and complete/incomplete states.
  • Full CRUD management for posts, comments, categories, and users.
  • A login system that locks out an account after repeated failed attempts, disabling the form for a cooldown period to blunt brute-force attacks.

Technologies & Approach

Built on plain PHP and MySQL with Ajax/jQuery for dynamic interactions, Chart.js for the dashboard visualizations, and Bootstrap for the public-facing responsive design.

PHP MySQL Ajax jQuery Bootstrap Chart.js

Challenges

This was my first PHP project, so the central challenge was learning secure backend development practices from the ground up: protecting against SQL injection and cross-site scripting, validating input on both client and server, and enforcing database-level data integrity - all without an existing framework doing it for me.

How They Were Solved

I designed security in layer by layer rather than bolting it on afterward: parameterized queries and input sanitization against injection and XSS, server-side validation backed by client-side validation for UX, database constraints for data integrity, and the account lockout logic described above for login attempts.

Outcome & Value Created

A working, reasonably sophisticated CMS that gave me hands-on command of Ajax, PHP syntax, date/time handling, and - most importantly - practical security practices that directly carried into the larger ColdFusion/Adilas projects that followed.
