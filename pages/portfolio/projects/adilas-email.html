Adilas E-mail Engine

A highly configurable transactional email system for AFB - 80+ settings, 37 dynamic template variables, and 13 distinct email types - covering everything from quotes and invoices to receivables.

Quick Facts
RoleSole developer
ClientAFB / Adilas
Scope80+ settings, 37 variables, 13 email types
Templates5 customizable HTML template slots

The Problem

AFB needed advanced, per-corporation transactional email functionality - quotes, invoices, receivables, and general notifications - that each customer could customize to their own specifications, rather than a single fixed template for everyone.

My Role

Sole developer; the project expanded considerably in scope as it was being built out.

What I Built

  • Over 80 settings for customizing the default e-mail template to a corporation's specifications.
  • 37 dynamic variables that populate different content per customer profile and e-mail type.
  • Storage for five additional custom HTML templates, each able to use the same variable system.
  • 13 distinct e-mail types spanning quotes, invoices, general correspondence, and receivables.

Technologies & Approach

Built on the Adilas/AFB application stack with a templating and dynamic-variable substitution layer so one engine could serve many differently branded, differently configured corporations.

Templating Engine Dynamic Variables Transactional Email

Challenges

The project began much smaller than it ended up - new settings, variables, and email types kept getting added as real needs surfaced, and by the end it was a significantly larger system than originally scoped.

How They Were Solved

Rather than resist the growth, I kept the settings/variable architecture generic enough to absorb new requirements without structural rewrites each time - and the experience directly changed how I scope similar projects since: plan out full functionality as much as possible up front, while staying realistic that some problems only reveal themselves mid-project.

Outcome & Value Created

A flexible, reusable email engine that could serve many corporations' differing branding and workflow needs from one system, plus a lasting lesson in project scoping that I now apply at the start of similar work instead of discovering it the hard way.
