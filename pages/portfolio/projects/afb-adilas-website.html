Unified AFB/Adilas Website

A shared-asset, session-based website architecture that let AFB and Adilas present content from the same codebase while each retained their own independent branding and customization.

Quick Facts
RoleSole developer
ClientAFB & Adilas
TechSession-based rendering, shared asset library
GoalOne codebase, two independently branded sites

The Problem

AFB and Adilas were closely related but separately branded properties that were maintaining largely duplicate websites. They needed to share a base of common content and code while still being able to fully customize their own pages independently.

My Role

Sole developer responsible for restructuring AFB's website so it could share infrastructure with Adilas.

What I Built

  • A shared library of commonly used assets and content usable by both properties.
  • Session-based logic so each entity's own code/content changes only affect its own pages, while shared content updates propagate to both automatically.
  • Two live entry points - an AFB entrance and an Adilas entrance - both drawing from the same underlying website.

Technologies & Approach

Session-based conditional rendering layered over a shared asset library, so the same request-handling code could serve either brand correctly depending on which entrance a visitor came through.

Session-Based Rendering Shared Asset Architecture Multi-Brand Websites

Challenges

The real difficulty wasn't any single piece of code - it was merging two previously separate sets of assets and content into one cohesive whole that both properties could rely on, without either one losing the ability to customize what mattered to them.

How They Were Solved

I used session techniques to determine which "entrance" a visitor was in, then built the shared asset layer so common content and code served both, while entity-specific overrides stayed cleanly separated and were layered on top rather than forked into two codebases.

Outcome & Value Created

A single, shared website architecture that removed the ongoing cost of maintaining near-duplicate sites for two related brands, while preserving each brand's own identity and customization - directly reducing long-term maintenance overhead.
