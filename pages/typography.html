Typography

This section covers the various typography elements available in DevDocs.

Headings

Headings are defined with <h1> through <h4> tags. The default font size and weight is set in styles.css. Headings can be used to create a table of contents for a page, and can be linked to directly with the #id in the URL.

Use h1 once per page as the page title. Use h2–h4 for sections and sub-sections. Headings are automatically picked up by the right-hand outline and scroll-spy system:

  • h1 - Page title (one per page)
  • h2 - Major section
  • h3 - Sub-section
  • h4 - Minor sub-section
ℹ Best Practice

Always give headings unique, descriptive id attributes. This ensures stable deep-link URLs and predictable scroll-spy behaviour.

Text Styles

DevDocs supports a few text styles for emphasis and clarity. These include:

  • <strong> - for strong emphasis (bold)
  • <em> - for emphasis (italic)
  • <code> - for inline code snippets
  • <mark> - for highlighting text
  • <del> - for strikethrough text
  • <ins> - for inserted text (underline)
  • .text-muted - muted text
Note: These text styles can be combined for additional emphasis.

Ordered list example:

  1. <ol> - for ordered lists
  2. <ul> - for unordered lists
